# OrganizaAI

Aplicação web para organização de projetos e tarefas, desenvolvida como projeto prático de aprendizagem em desenvolvimento de software.

O OrganizaAI evoluiu de uma implementação local baseada em JSON para uma aplicação web com PostgreSQL, API REST, autenticação, sessões e isolamento de dados por usuário.

## Estado atual

O projeto possui:

- cadastro de usuários;
- login e logout;
- sessões persistidas no PostgreSQL;
- senhas armazenadas com hash;
- projetos e tarefas separados por usuário;
- CRUD completo de projetos;
- CRUD completo de tarefas;
- PostgreSQL hospedado no Supabase;
- API REST com Express;
- interface web integrada;
- validações HTTP;
- testes automatizados;
- testes de integração com PostgreSQL;
- Git e GitHub.
